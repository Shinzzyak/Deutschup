## 2. 🔴 KRITIS — Security Vulnerabilities

### 🚨 CRITICAL: Service Role Key in Client Bundle
**Severity:** 🔴 CRITICAL (10/10)
**File:** `src/lib/supabase.ts`
**Bug:**
```ts
const supabaseKey = import.meta.env.VITE_SUPABASE_SERVICE_ROLE_KEY  // ← SERVICE KEY!
    || import.meta.env.VITE_SUPABASE_SERVICE_KEY
    || import.meta.env.VITE_SUPABASE_ANON_KEY;
```
**Konfirmasi:** `.env` has `VITE_SUPABASE_SERVICE_ROLE_KEY=sb_secret_CMOB8irSTvgtd1GsdHYYmw_w2utYpg-` dan Vite **inline semua** `import.meta.env.VITE_*` ke production bundle. Key ini udah dikonfirmasi ada di `dist/assets/index-BiMxCQLr.js`.

**Impact:** Service role key = bisa **bypass semua RLS policies** di Supabase. Siapapun yang buka halaman → inspect source → copy key → akses semua data di DB.

**Fix (15 menit):**
1. Hapus `VITE_SUPABASE_SERVICE_ROLE_KEY` dari `.env` 
2. Ganti fallback di `supabase.ts` jadi anon key **doang** (tujuan awal anyway):
   ```ts
   const supabaseKey = import.meta.env.VITE_SUPABASE_ANON_KEY;
   ```
3. Deploy ulang.
