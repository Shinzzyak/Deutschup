## I. New Patterns

### Netzwerk Sequencing Rule

**Rule:** Grammar topics must follow Netzwerk Neu ordering, not arbitrary placement.

**Why:** Proven progression for German learners.

### Goethe Alignment Rule

**Rule:** Curriculum must prepare for Goethe exams at each level.

**Why:** Measurable outcomes, recognized certifications.

### Level Placement Rule

**Rule:** Grammar topics must be placed at the earliest level where they're needed.

**Why:** Learners need tools as early as possible.

### Lesson Duration Rule

**Rule:** Lesson duration must match topic complexity, not fixed 10 minutes.

**Why:** Complex topics need more time for comprehension.
